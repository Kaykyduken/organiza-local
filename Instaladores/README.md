# Instalar o OrganizaLocal

Escolha o arquivo do seu sistema operacional.

| Sistema | Arquivo | Como instalar |
| --- | --- | --- |
| **Windows 10/11** | [OrganizaLocal-Setup-1.0.0.exe](OrganizaLocal-Setup-1.0.0.exe) | Dê dois cliques e siga o assistente. O Python já vem incluído. |
| **Ubuntu, Debian, Linux Mint e Pop!_OS** | [organizalocal_1.0.0_all.deb](organizalocal_1.0.0_all.deb) | Abra o pacote no instalador do sistema ou execute `sudo apt install ./organizalocal_1.0.0_all.deb` nesta pasta. |

Depois da instalação, abra **OrganizaLocal** pelo menu de aplicativos do seu sistema.
